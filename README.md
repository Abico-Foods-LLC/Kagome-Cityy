# Kagome City — Жимсний хот 🍎🥕

Kagome брэндийн 3D боловсролын тоглоом: жимсний хотоор чөлөөтэй аялж, жимс түүж, тоо бодох / унших / логикийн сорил давж, жимсэн машин жолоодож, ширэнгээр гүйнэ (Jungle Runner).

Бүх дүрслэл procedural (Three.js) — гадны 3D модел, texture файл ашиглаагүй. Зөвхөн Kagome бүтээгдэхүүний 8 зураг (WebP).

## Ажиллуулах

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ хавтас — статик хостинг (Vercel, GitHub Pages, Netlify)
npm run preview
npm test           # GameState unit test (Vitest)
```

## Онцлог

- **Жимсний хот** — 6 бүлэгт аялал (жимс түүх, тоо бодох, унших, логик, машин, гүйлт), 10 mascot дүр + хувцас (Kagome маркет), шүүсний лаборатори mini-game, өдрийн даалгавар, жимс дахин ургах
- **Хотын activity** — 🎣 загас барих (сувгийн эрэг, timing), 🌱 миний талбай (үр авах → тарих → услах → хураах, реал цаг), 📬 хүргэлтийн даалгавар (захиалгын самбараас хугацаатай, машинаар хурдан), ❗ иргэдийн өдрийн хүсэлт (жимс / Луувсайтай уулзах)
- **🚪 Байшингийн хаалга → өөр ертөнц** — байшин бүрийн хаалга ойртоход нээгдэнэ. **Хулууны гэр → 🎃 Хортон хамгаалалт**: шөнийн фермд төвийн аварга хулуу base руу давалгаагаар ирэх царайтай хортон (хорхой, хэрээ, номин, слайм)-ыг шүүсний цацуураар буудна (цусгүй — конфетти); зоосоор хашаа, цацуур цамхаг, хамгаалагч NPC, хүч, засвар авна; base унавал оноо → од. Хулгана: товшоод түгжинэ (shift-lock), дэлгэцийн голд crosshair, aim assist; утас: чирж чиглүүлж 🚿 дарна. Өрөөнийхөн хамт орвол co-op (host хортонг удирдана). Бусад 4 байшин удахгүй.
- **Kagome маркет** — од зарцуулах 5 tab: хувцас/аксессуар, машины будаг + чимэг (туг, антенн, хайрцаг), Луувсайн хүзүүвч/бандана/малгай, алхахад гарах trail эффект (од/дэлбээ/солонго), талбайн дэргэдэх «Миний булан»-гийн чимэглэл
- **Алтан лууван ×20** — хотоор нуусан цуглуулга; ойртоход чимээ, бүгдийг олбол 300 од + Алтан титэм
- **Сорил** — тоо бодох / унших / логик тус бүр 15 асуулт, Бага (6–8) / Ахлах (9–12) түвшин цэснээс
- **Амьд хот** — алхдаг иргэд (хоорондоо ярилцана, толгой дээрх emoji бөмбөлөг), тариаланч, худалдагч, загасчин, дагадаг нохой (Луувсай — унасан иргэнийг долоож босгоно), нугас (ойртвол зугтана), муур (илж болно), эрвээхий, шувуу; өдөр-шөнө, бороо/солонго, 4 улирал (5 мин тутам)
- **Jungle Runner** — 5 үе + төгсгөлгүй горим, power-up (бамбай, соронз, jetpack, ×2), рекордын самбар
- **Дүрслэл** — toon shading, дугуй хязгаар, lens flare, depth of field, contact shadow, particle, procedural texture; хөгжим өдөр/шөнө/машин/өвөл хувилбартай
- **👥 Хамт тоглох** — тоглоом нээхэд **нийтийн хотод** автоматаар нэгдэнэ (бүгд нэг хотод; 8-аас олон бол дараагийн хот руу автоматаар; цэснээс унтраана). Эсвэл «Хувийн өрөө үүсгэх» → линкийг найздаа илгээ (8 хүртэл); сервергүй P2P (WebRTC, Trystero). Бие биеэ харна, өргөж шиднэ (хулганы товшилт / Q), иргэд/эвдрэл/машин/цаг бүгдэд ижил (host = эхэлж орсон хүн), `T` бэлэн үг/emoji чат, бусдын амжилт toast-оор. Тоглогч бүр өөрийн ахицтай. Зарим хатуу сүлжээнд холбогдохгүй байж болно.
- **Утас** — хэвтээ (landscape) байрлалд зориулагдсан (босоо бол сануулга); автомат чанар; `?fps` параметрээр FPS overlay (`http://localhost:5173/?fps`)

## Удирдлага

| Үйлдэл | Гар | Утас / Gamepad |
|---|---|---|
| Алхах | `W A S D` / сум | Зүүн joystick |
| Гүйх | `Shift` | 🏃 товч / joystick бүтэн |
| Үсрэх | `Space` | ↑ товч / A |
| Харилцах, машинд суух/буух | `E` | E товч / B |
| Камер | Хулгана чирэх, `Q`/`R` | Дэлгэц чирэх / баруун stick |
| Газрын зураг | `M` | 🗺 |
| Цэс | `Esc` | ⏸ |
| Давхар үсрэлт / өнхрөх | `Space ×2` / `C` | ↑↑ / 🔄 |
| Иргэн / Луувсай өргөх, буулгах | Хулганы товшилт | Дэлгэц товших |
| Луувсайд бөмбөг шидэх | `F` | 🎾 товч |
| Photo mode (HUD нуугдана, чөлөөт камер, PNG) | `P` / 📷 | 📷 товч |
| Чат (өрөөнд) | `T` / 💬 | 💬 товч |
| Тоглогч өргөх (өрөөнд) | Хулганы товшилт, `Q` шидэх | Дэлгэц товших |
| Муур илэх | `E` (сандлын дэргэд) | E товч |
| Өргөсөн иргэнийг шидэх | `Q` | — |
| Emote | `1` `2` `3` | — |
| Zoom | Хулганы дугуй | Хоёр хуруу |

**Jungle Runner:** `← →` эгнээ, `↑` үсрэх, `↓` гулсах (агаарт — шумбах), `E` уяанаас зүүгдэх. Утсан дээр шудрах.

```

  core/    content.js  агуулга (жимс, аялал, асуулт, бүтээгдэхүүн, түвшин)
           state.js    ахиц (localStorage)
           input.js    гар / мэдрэгч / gamepad нэгдсэн удирдлага
           audio.js    procedural дуу, хөгжим, ambient
           ui.js       toast, modal, HUD туслахууд
  gfx/     materials.js toon shading, outline, ус, салхи shader
           textures.js  canvas texture (өвс, зам, мод, нүүр...)
           sky.js       тэнгэрийн градиент, үүл
           post.js      bloom + vignette
           particles.js instanced particle
           merge.js     статик mesh нэгтгэл (draw call оновчлол)
  world/   character.js chibi дүр + animation state machine
           props.js     мод, байшин, хашаа, машин, бүтээгдэхүүн...
           town.js      хотын байршил, collider
           animals.js   нохой, нугас, муур
           bubble.js    толгой дээрх emoji бөмбөлөг
  town/    TownScene.js хотын gameplay (хөдөлгөөн, камер, машин, аялал, minimap)
           juice.js     шүүсний лаборатори mini-game
           fishing.js   загас барих (3D timing)
           farm.js      миний талбай (тарих/услах/хураах)
           delivery.js  хүргэлтийн даалгавар + HUD
           requests.js  иргэдийн өдрийн хүсэлт
           shop.js      Kagome маркет UI (5 tab)
           home.js      «Миний булан» чимэглэл
           carrots.js   алтан лууван ×20
           ball.js      Луувсайн бөмбөг

           room.js      Trystero өрөө, линк, нэр, peer жагсаалт
           remote.js    бусад тоглогчдын avatar/label

  defense/ DefenseCore.js  хортон хамгаалалтын логик (Vitest)

           pests.js        хортоны дүрүүд, хамгаалагч
  runner/  RunnerCore.js runner логик (дүрслэлгүй)
           RunnerScene.js runner дүрслэл, камер, эффект
```
